# Сканворды для чата

Telegram-бот с мини-приложением: один сканворд на чат, все участники решают его
одновременно. Работает на Telegram Serverless (`@tgcloud/cli`), своего сервера нет.

## Как это устроено

| Папка | Что там |
|---|---|
| `tgcloud/` | Код, который исполняется в облаке: схема базы, обработчики сообщений, эндпоинты мини-приложения |
| `src/` | Мини-приложение (Preact + Vite). `npm run build` собирает его в `dist/` |
| `tools/dict/` | Словарь: слова с уровнем известности и 2–3 определениями |
| `tools/generator/` | Генератор: раскладки сеток и заполнение их словами |
| `data/puzzles/` | Готовые серии сканвордов |

Игра: `/play` в чате создаёт сканворд и кнопку. Мини-приложение раз в секунду
вызывает `sync`: отправляет набранные буквы и курсор, получает чужие изменения.
Верно собранное слово закрепляется и засчитывается тому, кто вписал последнюю
букву. Ответы на клиент не передаются.

## Команды

```
npm run dev                    # интерфейс в браузере с демо-сервером (без Telegram)
npm run deploy                 # собрать мини-приложение и выложить всё в облако
npx tgcloud migrate            # применить изменения схемы базы

npm run dict                   # собрать tools/dict/dictionary.json из частей
npm run masks -- 100           # добавить 100 раскладок в tools/generator/masks.json
npm run generate -- s9 300 1   # серия s9 из 300 сканвордов, зерно 1
npm run upload -- s9 --retire  # залить серию в бота, остальные снять с ротации
```

В облачной среде Claude Code перед командами `tgcloud` нужен
`export NODE_USE_ENV_PROXY=1`, иначе CLI не видит прокси.

## Словарь

`tools/dict/reviewed/*.jsonl` — вычитанный старый словарь, `tools/dict/new/*.jsonl` —
новые слова по темам. Правила и формат описаны в `tools/dict/BRIEF.md`, проверка —
`node tools/dict/check.mjs <файл>`. Уровни: 1 — знает каждый, 2 — книжное или
специальное, 3 — редкое. Генератор берёт в сканворд не больше шести слов уровня 2
и ни одного слова уровня 3; слово не повторяется в течение 30 сканвордов подряд,
а его определения чередуются.
