# Словарь для сканвордов: правила

Мы делаем русские сканворды для игры компанией друзей в чате (взрослые, без
специальной эрудиции). Игроки жалуются на **качество слов и вопросов**: много
«кроссвордизмов» (ОДР, АКР, ТОЛ, БОА), скучные и неточные определения. Словарь —
главное, от чего зависит удовольствие от игры. Пишите так, как писал бы хороший
редактор журнала сканвордов.

## Формат

Файл JSONL, одна запись на строку:

```
{"w":"ОКОП","t":1,"c":["Траншея на фронте","Укрытие пехотинца","Яма с бруствером"]}
```

- `w` — ответ: ЗАГЛАВНЫМИ, только буквы А–Я, **Ё пишется как Е**, 3–10 букв, без
  дефисов и пробелов.
- `t` — уровень слова:
  - `1` — знает любой взрослый, слово живое и приятно отгадывается (СОСЕД, ШАШЛЫК, ФОНТАН);
  - `2` — знают многие, но слово книжное, специальное или устаревшее (ДЕСНИЦА, ЗАИМКА, ЯРЛ);
  - `3` — редкое слово или кроссвордизм, которое угадают единицы (ОДР, АКР, ТОЛ);
  - `0` — выбросить: не существительное в начальной форме, слова нет или оно
    написано с ошибкой, аббревиатура, грубое/оскорбительное/неприятное слово,
    слово с равноправными вариантами написания.
- `c` — определения: **3 разных для слов из 3–4 букв, 2 разных для слов из 5+ букв**
  (у `t:0` поле `c` не нужно).
- `"p":1` — добавить для имён собственных (ПАРИЖ, ПУШКИН, ВОЛГА).

## Какие слова годятся

Существительные в именительном падеже единственного числа (или только
множественного, если единственного нет: НОЖНИЦЫ, ДЖИНСЫ). Глаголы, прилагательные,
наречия, междометия — `t:0`. Имена собственные допустимы, только если общеизвестны.

## Какие определения годятся

- **Коротко: не длиннее 42 знаков**, лучше 15–30. Определение печатается в
  маленькой клетке сканворда.
- Стиль сканворда: назывное предложение без точки в конце, с заглавной буквы.
  «Траншея на фронте», «Живёт за стеной», «Цель футболиста».
- **Точно**: по определению должно подходить именно это слово, а не десяток других.
  «Прибор» для АППАРАТ и «Бедность» для НУЖДА — плохо. Добавьте деталь.
- **Без однокоренных слов** и без самого ответа в определении.
- **Интересно**: лучше образ, деталь быта, игра смысла, чем словарная статья.
  «Серебро в волосах» (СЕДИНА), «Тянул баржу по Волге» (БУРЛАК), «Рыжая плутовка»
  (ЛИСА). Но без натужных шуток и без загадок, которые нельзя отгадать.
- Определения одного слова должны заходить **с разных сторон** (разные значения,
  разные образы), а не перефразировать друг друга.
- Никакой политики, насилия ради насилия, пошлости. В тексте определения буква ё
  пишется как ё.
- Факты проверяйте по памяти строго: неверное определение хуже скучного.

## Проверка

Перед тем как закончить, обязательно запустите проверку и исправьте все `ERROR`
(предупреждения `WARN` просмотрите глазами: это подсказки, не приговор):

```
node tools/dict/check.mjs <ваш файл> [--review tools/dict/chunks/N.tsv | --new]
```
